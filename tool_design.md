Описание инструментов для LLM-агента

Калькулятор — выполняет точные вычисления, принимает числа и операцию, возвращает результат и сообщает об ошибке при неверных данных.

Поиск по файлам — ищет нужную информацию в документах, принимает документ и запрос, возвращает найденный фрагмент и сообщает, если он не найден.

База данных — получает статус обращения по его номеру и сообщает об ошибке, если обращение не найдено или сервис недоступен.

API — обрабатывает один или несколько документов, возвращает результат обработки и сообщает, если документ не удалось обработать.

Планировщик — проверяет свободное время для встречи по дате, времени и длительности и сообщает об ошибке, если календарь недоступен.
